# Quick-Payment — ОСББ «Донця 2А-Ініціатива»

Сторінка швидкої оплати на основі `SapozhnikUA/PE-QuikPaymentPage`.

## Можливості
- QR-платіж НБУ у форматі 002;
- вибір рахунку ОСББ;
- окремі фіксовані призначення для кожного рахунку;
- автоматичне формування призначення з номера квартири / о/р;
- довідник квартир і нестандартних номерів (`apartments.json`);
- довільна сума;
- повні платіжні реквізити та копіювання;
- довгі посилання з параметрами — без коротких посилань і `links.json`;
- захищений режим адміністратора `?admin` для оновлення коду.

## Додавання платіжного рахунку

У `config.php` додайте об’єкт до масиву `accounts` з унікальним `id`. Усередині кожного рахунку вкажіть:
- `purposes` — список доступних для цього рахунку фіксованих призначень;
- `default_purpose` — призначення, вибране за замовчуванням.

Призначення з одного рахунку не показуються під час вибору іншого рахунку.

## Сервер

Потрібен PHP 7.4+ та права веб-користувача на запис `config.php`. Для створення робочої конфігурації використовуйте `config.example.php`; перший PHP-рядок у конфігурації не видаляйте.

Робочий `config.php` не перезаписується автоматичним оновленням. Якщо переходите зі старого формату, перенесіть `purposes` і `default_purpose` всередину відповідних об’єктів у `accounts`.
