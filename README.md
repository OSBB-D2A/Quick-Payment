# Quick-Payment — ОСББ «Донця 2А-Ініціатива»

Сторінка швидкої оплати на основі `SapozhnikUA/PE-QuikPaymentPage`.

## Можливості
- QR-платіж НБУ у форматі 002;
- вибір рахунку ОСББ;
- вибір призначення платежу з підготовленого списку;
- автоматичне формування призначення з номера квартири / О/р;
- довідник квартир і нестандартних номерів (`apartments.json`), зокрема значень на кшталт `140/1`, `760-761`, `VI підв.` та інших;
- довільна сума;
- повні платіжні реквізити та копіювання;
- довгі посилання з параметрами;
- короткі посилання через `links.json`;
- захищене автозбереження коротких посилань через `save.php`;
- режим адміністратора `?admin`.

## Додавання рахунку

У `config.php` додайте новий об'єкт до масиву `accounts` з унікальним `id`. Після цього рахунок автоматично з'явиться у списку.

Коротке посилання зберігає `account + sum + purpose`, тому однакове призначення та сума для різних рахунків не конфліктують.

## Сервер

Потрібен PHP 7.4+ та права веб-користувача на запис `config.php` і `links.json`.

> Не публікуйте справжній `config.php` у Git, якщо в ньому буде задано пароль/службові сесії. Для production краще тримати робочий конфіг поза публічним репозиторієм або виключити його з Git.

## Швидкі посилання

Для створення короткого посилання відкрийте сторінку з `?admin`, задайте пароль, оберіть рахунок/суму/призначення та натисніть «Копіювати посилання».
